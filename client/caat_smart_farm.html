🚜 밭갈기 · 1차시
스마트팜이란 무엇일까?
데이터로 농사를 짓는 시대 — 센서, AI, 인터넷이 만나는 곳을 탐험해봐요.
⏱ 45분🎯 디지털 리터러시📌 ESP32 키트
🌍왜 스마트팜이 필요할까?

지구 온난화로 농작물 재배 조건이 달라지고 있어요. 기온이 1°C 오를 때마다 벼 수확량이 약 6% 줄어든다는 연구 결과가 있습니다.

스마트팜은 센서로 흙의 수분·온도·빛을 실시간 측정하고, 그 데이터로 물 주기·온도를 자동화해요. 낭비는 줄이고, 수확량은 늘리는 거죠.

🧠오늘 배울 핵심 개념

센서(Sensor) — 온도·빛 같은 물리 신호를 전기 신호로 바꾸는 장치예요.

마이크로컨트롤러(MCU) — 센서 신호를 처리하는 초소형 컴퓨터. 우리가 쓸 ESP32가 바로 MCU예요.

IoT(사물인터넷) — 센서 데이터를 인터넷으로 전송해 어디서든 확인하고 제어할 수 있어요.

🚜 밭갈기 · 2차시
ESP32 첫 연결 — 내 스마트팜 시작
하드웨어를 PC에 연결하고 첫 번째 코드를 업로드해봐요!
⏱ 45분🎯 컴퓨팅 사고력
🔌ESP32 셋업 순서

① ESP32를 USB 케이블로 PC에 연결하세요.

② Arduino IDE → 보드: ESP32 Dev Module 선택

③ 포트(COM 또는 /dev/tty...) 선택

④ 아래 코드를 붙여넣고 업로드 버튼(→)을 누르세요!

💻첫 번째 코드 — LED 깜빡이기
// ESP32 내장 LED 깜빡이기 (핀 2번) void setup() { pinMode(2, OUTPUT); Serial.begin(115200); Serial.println("스마트팜 시작!"); } void loop() { digitalWrite(2, HIGH); delay(1000); digitalWrite(2, LOW); delay(1000); }
🎯2차시 미션 — delay 값 바꿔보기
delay 값을 바꿔서 LED 깜빡임 속도를 바꿔봐요. 변화를 오른쪽 튜터에게 설명해보세요!
🚜 밭갈기 · 3차시
센서 데이터 읽기 — 온습도 + 토양수분
DHT22 센서와 토양수분 센서를 연결하고 데이터를 시리얼 모니터에 출력해봐요.
⏱ 45분🎯 데이터 소양
💻온습도 + 토양수분 센서 코드
// DHT22 + 토양수분 센서 동시 읽기 #include <DHT.h> #define DHTPIN 4 #define DHTTYPE DHT22 #define SOIL_PIN 34 DHT dht(DHTPIN, DHTTYPE); void setup() { Serial.begin(115200); dht.begin(); } void loop() { float temp = dht.readTemperature(); float hum = dht.readHumidity(); int soil = analogRead(SOIL_PIN); Serial.printf("온도:%.1f°C 습도:%.0f%% 토양:%d\n", temp, hum, soil); delay(2000); }
🎯3차시 미션 — 내 교실 vs 농협대 데이터 비교
센서 값을 위 농협대 실시간 데이터와 비교해봐요. 왜 차이가 날까요? 튜터에게 물어보세요!
🌿 가꾸기 · 7차시
바이브코딩 — AI에게 코드를 부탁해봐요!
자연어로 AI에게 원하는 코드를 요청하는 "바이브코딩" 기술을 배워봐요.
⏱ 45분🎯 AI 소양✨ 핵심 차별화
🤖바이브코딩이란?

코드를 한 줄씩 타이핑하는 대신, AI에게 "내가 원하는 것"을 자연어로 설명해서 코드를 얻는 방법이에요.

중요한 건 AI가 만든 코드를 이해하고 수정할 수 있어야 한다는 거예요. 그냥 복붙만 하면 진짜 농부가 아니죠!

✨바이브코딩 실습 — 오른쪽 튜터에게 직접 요청해봐요
아래 예시처럼 오른쪽 허수아비 튜터에게 자연어로 코드를 요청해보세요!
💬 바이브코딩 프롬프트 예시
토양수분 값이 30% 이하로 떨어지면 자동으로 펌프를 켜고, 70% 이상이 되면 멈추는 ESP32 코드를 만들어줘. 펌프는 GPIO 26번 핀에 연결했어. 한국어 주석도 달아줘.
튜터가 코드를 만들어주면, 모르는 부분을 또 물어보세요!
